# COMP2610 / COMP6261 Information Theory

## 这门课学什么

这是一门**信息论导论**。核心问题是：如何度量信息，以及数据压缩和可靠通信的理论极限是什么。

主要内容：

- 概率论、贝叶斯推断与概率分布
- 熵、相对熵（KL divergence）与互信息
- 重要不等式、大数定律、典型集与 AEP
- 无损压缩、符号编码、算术编码与信源编码定理
- 噪声信道、信道容量、分组码、线性码与信道编码定理
